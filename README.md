# Simple Sidebar Toggle App 🚀

> A lightweight and simple web application featuring a collapsible sidebar navigation bar, built with vanilla web technologies.

---

## 📌 Overview

This project is an interactive webpage featuring a navigation sidebar and toggle buttons (`Open` / `Close`). It was built to practice and apply DOM manipulation concepts, event handling, and CSS layout styling[cite: 1, 2, 3].

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for the navigation elements and buttons[cite: 1].
- **CSS3:** Styling, layout arrangement, and visibility toggling classes (`.hide`)[cite: 3].
- **JavaScript (Vanilla):** Event listeners (`onclick`) and dynamic class manipulation[cite: 2].

---

## ✨ Features

- Clean and minimal user interface[cite: 3].
- Instant, smooth interactivity without page reloads[cite: 2].
- Lightweight code with zero external dependencies or heavy frameworks.
